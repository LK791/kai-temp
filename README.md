## 字段与读取

个股“昨天收盘”来自同花顺SDK官方历史昨收，除权除息日已调整。日涨跌幅需结合当天不复权收盘价；资金流文件本身没有个股当天收盘价。

行业指数有“昨收、开盘、最高、最低、收盘、涨跌额、涨跌幅、成交量、成交额”。大盘为上证指数000001与深证成指399001，并保存市场列。指数涨跌幅单位为百分数，例如1.23表示1.23%。

```python
import pandas as pd
stocks = pd.read_csv('ths_a_stock_fundflow_20250101_20261006.csv',
                     dtype={'股票代码': str, '二级行业代码': str}, parse_dates=['日期'])
industries = pd.read_csv('ths_industry2_indices_20250101_20261006.csv',
                         dtype={'二级行业代码': str}, parse_dates=['日期'])
market = pd.read_csv('sse_szse_market_indices_20250101_20261006.csv',
                     dtype={'指数代码': str}, parse_dates=['日期'])
```

## 已知数据限制

- 个股文件仅采集沪深股票，原目录筛选已发现至少71只沪深股票遗漏；完整市场覆盖问题尚未修复。未返回股票日记录没有填充成零。
- 二级行业采用当前同花顺分类，不是按历史日期恢复的分类；部分行业指数含北交所成分，因此行业量额不能直接等同于此个股表的聚合。
- 部分资金流源数据存在异常，不能把格式和文件校验通过视为所有金额准确。
- 被动买入小单、被动卖出小单是推算值；原负残差按用户指定规则置零，零值不都代表原始交易金额真实为零。
- 个股官方昨收2142993条均有返回；抽取64股26554条重新请求一致。行业及大盘日期完整，无重复日期代码。
